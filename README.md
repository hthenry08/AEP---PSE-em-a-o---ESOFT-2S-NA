Descrição:

Aplicação em linguagem C, executada em terminal, desenvolvida como Atividade de Estudo Prático (AEP) dos cursos de Engenharia de Software e Análise e Desenvolvimento de Sistemas da Universidade Cesumar (UNICESUMAR). O sistema tem como objetivo apoiar equipes escolares e de saúde no planejamento, registro e acompanhamento de ações coletivas do Programa Saúde na Escola (PSE), permitindo cadastrar, listar, pesquisar, atualizar a situação das ações e gerar um resumo geral da participação. O projeto utiliza apenas dados fictícios e coletivos, sem armazenar informações individuais de estudantes.
